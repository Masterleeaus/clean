## 🎯 Guild Responsibilities

### Design System & UX (Agent-21 leads)
- Maintain design system and component library
- Ensure WCAG 2.1 AA accessibility compliance
- Define design tokens and patterns
- Conduct accessibility audits
- Ensure cross-app UI/UX consistency

### Component Implementation (Agent-22 leads)
- Implement UI components following design system
- Develop responsive designs (mobile-first)
- Implement theme system (light/dark modes)
- Optimize component performance
- Conduct visual regression testing

### App Development (All 14 app agents)
- Develop and maintain app features
- Follow design system and accessibility standards
- Implement offline capabilities (where applicable)
- Maintain multi-tenancy integrity
- Achieve >80% test coverage

### Cross-App Coordination
- Ensure design consistency across 14 apps
- Share reusable components
- Coordinate on shared features
- Handle multi-channel concerns (Chatbot PWA)
- Knowledge sharing and best practices

## ⚠️ Guild Critical Rules

### Design System
- ✅ All components must follow design system
- ✅ Design changes require guild review
- ✅ Accessibility (WCAG AA) is mandatory
- ❌ Never bypass design system
- ❌ Never hardcode colors/spacing

### Development
- ✅ Code must follow linting standards
- ✅ Test coverage must be > 80%
- ✅ Multi-tenancy must be maintained
- ❌ Never commit without tests
- ❌ Never hardcode tenant data

### Coordination
- ✅ Designer Agent (21) approves design changes
- ✅ UI Agent (22) approves component implementations
- ✅ Guild meetings for architectural decisions
- ❌ Never make design decisions unilaterally
- ❌ Never change shared components without review
