# Review Knowledge

Reviews become durable engineering knowledge rather than disappearing into transient comments.

## Categories

- `pull-requests/`
- `architecture/`
- `code/`
- `security/`
- `performance/`
- `ai/`

A review summary records the reviewed baseline, changed scope, authorities involved, confirmed defects, risks, requested changes, accepted exceptions, evidence, outcome and reusable lessons. It links to the originating PR or review but does not duplicate the entire discussion.
