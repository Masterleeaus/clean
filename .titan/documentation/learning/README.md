# Learning Memory

This area turns completed work, failures and experiments into reusable engineering knowledge.

## Categories

- `lessons/`
- `failures/`
- `improvements/`
- `patterns/`
- `recommendations/`
- `experiments/`

Learning records must distinguish observed evidence from inference. A lesson is not promoted into Kernel policy automatically; policy changes require an Evolution proposal, validation and approval.

Useful records include the triggering task, problem, attempted approaches, result, evidence, affected capabilities, recommended reuse and conditions where the lesson does not apply.
