# Agent OS Dashboards

Generated summaries provide fast views of project state without replacing source evidence.

## Planned dashboards

- `executive.md`
- `engineering.md`
- `architecture.md`
- `ai.md`
- `releases.md`
- `health.md`

Each dashboard identifies its source commit, inputs, generator, freshness and links to underlying reports. Dashboards summarise; they do not create authority or conceal unresolved risks.

No dashboard is currently claimed as automatically generated. This directory defines the v1.0 contract.
