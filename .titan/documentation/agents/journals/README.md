# Agent Engineering Journals

Each persistent agent role maintains a concise engineering journal for continuity between sessions.

## Recommended journals

- `architecture/`
- `backend/`
- `frontend/`
- `integration/`
- `debugging/`
- `security/`
- `documentation/`

Each entry records:

- agent role and task ID;
- branch and source baseline;
- work completed;
- decisions made or requested;
- problems encountered;
- escalations;
- validations and tests;
- remaining risks;
- lessons learned;
- handoff to the next agent.

Journals are not architectural authority. Decisions must be promoted into `documentation/decisions/`, reusable lessons into `documentation/learning/`, and current task state into `documentation/status/` or `documentation/progress/`.
