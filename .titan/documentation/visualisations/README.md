# Generated Visualisations

Visualisations are generated from the World Model, Knowledge Graph and registries.

## Categories

- `architecture/`
- `dependencies/`
- `capabilities/`
- `workflows/`
- `events/`
- `domains/`
- `sequences/`
- `states/`

Every diagram must identify source commit, generator, input graph or registry, freshness and a machine-readable companion where possible. Hand-drawn or manually curated diagrams belong in `/docs/architecture` unless they are explicitly identified as Agent OS authored design.

No automatic diagram generation is claimed operational yet.
