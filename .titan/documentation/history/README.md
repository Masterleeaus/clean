# Engineering History

History preserves significant system states and transitions without treating old material as current authority.

## Categories

- `snapshots/`
- `evolution/`
- `migrations/`
- `architecture/`
- `capabilities/`
- `workflows/`
- `policies/`
- `incidents/`

Each history record identifies the period, source baseline, superseding state, reason retained and links to related decisions or Chronicle entries. Historical source is evidence and institutional memory, not an instruction to restore obsolete code.
