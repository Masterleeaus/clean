# Engineering Progress

This area provides durable engineering progress rather than raw telemetry.

## Structure

- `roadmap/`
- `milestones/`
- `releases/`
- `completed/`
- `active/`
- `backlog/`
- `blockers/`
- `decisions/`
- `changelog/`
- `weekly/`
- `daily/`

Progress records must identify owner, status, baseline, dependencies, blockers, evidence and next action. Claude may generate summaries from accepted plans and runtime state, but human-approved scope and release decisions remain authoritative.

The current canonical implementation roadmap remains `/docs/plans/CURRENT_UPGRADE_PLAN.md`. Agent OS progress views derive from it rather than replacing it.
