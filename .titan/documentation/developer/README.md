This area explains how humans use and extend Titan Agent OS. Executable generators, scaffolds, hooks and validation tools belong in `/.titan/developer/`, not here.

Long-form project documentation remains under `/docs`; this directory contains Agent OS-specific human guidance or curated entry paths into those canonical documents.
