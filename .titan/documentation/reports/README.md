# Generated and Evidence-Backed Reports

Reports provide durable health views for humans, Claude and governance authorities.

## Categories

- `architecture-health/`
- `dependency-analysis/`
- `drift/`
- `technical-debt/`
- `security/`
- `performance/`
- `coverage/`
- `quality/`
- `ai/`
- `evolution/`

Every report must identify source commit, inputs, generator or author, confidence, freshness, findings, severity, evidence and recommended action. A report is evidence, not automatically an accepted decision or implementation plan.
