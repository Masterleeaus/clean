# Intelligence Layer

The Intelligence layer provides repository understanding rather than application code.

## Planned components

- World Model / Digital Twin
- Knowledge Graph
- capability graph
- dependency graph
- working, semantic, procedural, episodic and architectural memory
- incidents and lessons
- reasoning strategies: deductive, inductive, abductive, comparison, planning, repair and root-cause
- pattern discovery and controlled learning

Generated facts record source commit, evidence and confidence. Semantic relationships must not override source evidence or Kernel policy.

The v1.0 bootstrap defines the architecture and source registry. Continuous graph generation and semantic querying remain planned.
