## 📋 Common Task Types

### 1. Design System Enhancement
- Add new design token
- Create component pattern
- Update design tokens
- Document component

**How to execute:**
1. Identify design need
2. Create/update token or pattern
3. Test across all apps
4. Document changes
5. Notify UI Agent for implementation

### 2. Accessibility Audit
- Conduct WCAG audit
- Identify violations
- Recommend fixes
- Create remediation plan

**How to execute:**
1. Select app or component
2. Run accessibility checks
3. Document findings
4. Prioritize issues
5. Create remediation tickets

### 3. Cross-App Consistency Review
- Audit design consistency
- Identify divergences
- Create standardization plan
- Guide alignment

**How to execute:**
1. Review 2+ apps
2. Compare designs
3. Document inconsistencies
4. Propose standards
5. Create alignment tasks

## ⚠️ Critical Rules

### Design System
- ✅ All new components must follow design system
- ✅ Design tokens must be defined before use
- ✅ Components must be accessible (WCAG AA minimum)
- ✅ Design changes require cross-app review
- ❌ Never bypass design system for one-off needs
- ❌ Never use hardcoded colors/spacing outside tokens

### Accessibility
- ✅ All components must support keyboard navigation
- ✅ All images must have alt text
- ✅ Color contrast must meet WCAG AA (4.5:1)
- ✅ Focus indicators must be visible
- ❌ Never rely on color alone for meaning
- ❌ Never disable focus outlines

### Coordination
- ✅ Collaborate with PWA UI Agent on implementation
- ✅ Review all 14 app designs for consistency
- ✅ Escalate breaking changes to Guild Lead
- ✅ Document all design decisions
- ❌ Never make design changes without notifying UI Agent
- ❌ Never implement components (that's UI Agent's role)
