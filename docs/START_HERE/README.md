## ⚡ Quick Start (5 Minutes)

### Step 1: Access GitHub Actions
```
Go to: https://github.com/Masterleeaus/clean/actions
```

### Step 2: Select Workflow
```
Click: "ChatGPT Agent Master Dispatcher"
```

### Step 3: Run Action
```
1. Click "Run workflow" button
2. Select action: "analyze-structure" (recommended first)
3. Click "Run workflow"
4. Wait: ~5 minutes
```

### Step 4: Download Results
```
Workflow completes → Artifacts tab → Download results
```

## 🎯 Available Actions (Pick One)

### Recommended First Actions

**1. analyze-structure** (Start Here!)
- Analyzes repository layout
- Shows domains, extensions, packages
- Time: ~5 min
- Output: Markdown reports

**2. validate-extensions**
- Checks all extensions
- Validates manifests
- Time: ~3 min
- Output: Validation results

**3. export-command-registry**
- Lists all WorkCore commands
- Shows schemas
- Time: ~2 min
- Output: JSON file

### More Advanced Actions

- **validate-wizards** - Check wizard definitions
- **run-tests** - Discover test suite
- **test-capability** - Test specific command
- **audit-domain** - Audit WorkCore domain
- **analyze-dependencies** - Check PHP/Node deps
- **generate-docs** - Create API reference
- **export-schemas** - Export data models
- **export-command-registry** - Export all commands
