# Titan Zero Authority Map

```text
MagicAI host
├── authentication, users, subscriptions, entitlements
├── desktop UI and extension lifecycle
└── provider and platform configuration

WorkCore
├── company and membership context
├── permissions and operational domains
├── BusinessActionDispatcher
├── audit, outbox and domain events
└── authoritative records and server sync

Interaction Engine
├── definitions, sessions and transitions
├── user / user-plus-AI / delegated-AI modes
├── authority, confidence, evidence and abstention
└── offline interaction state and command preparation

Titan Zero five-tier AI
├── Tier 0 orchestrator
├── Tier 1 managers
├── Tier 2 assistants and specialists
├── Tier 3 action agents
└── Tier 4 governed tools

Titan Zero chatbot PWA
├── fourteen integrated apps
├── persistent chat and generative UI
├── local projections, drafts and outbox
├── device vault, sync and conflict centre
└── mobile/tablet experience
```

No layer may silently assume another layer's authority.
