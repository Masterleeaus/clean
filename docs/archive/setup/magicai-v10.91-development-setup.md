# MagicAI v10.91 — Minimal Developer Codebase

This package contains the editable Laravel/Vite source needed for development. Runtime dependencies, generated bundles, caches, logs, user uploads, demo videos, and the live `.env` were intentionally removed.

## Requirements

- PHP and extensions required by `composer.json`
- Composer
- Node.js and npm
- MySQL-compatible database

## Setup

```bash
composer install
npm ci
cp .env.example .env
php artisan key:generate
```

Configure database, mail, queues, storage, and provider credentials in `.env`.

Use one database setup path:

```bash
php artisan migrate --seed
```

Or import `database/magicai-reference.sql` when the migration history does not reproduce the packaged release database exactly.

Then run:

```bash
php artisan storage:link
npm run dev
php artisan serve
```

For a production-style frontend bundle:

```bash
npm run build
```

## Deliberately excluded

- `vendor/` — restore with `composer install`
- `node_modules/` — restore with `npm ci`
- `.env` — may contain installation-specific secrets
- `public/build/` — generated by Vite
- user/demo uploads and large promotional video files
- caches, sessions, compiled views, logs, debug output, and coverage files
- macOS metadata

## Source retained

Application code, routes, configuration, migrations, seeders, tests, Blade/templates, frontend source, theme source/static libraries, public entry files, lockfiles, and release documentation are retained.
