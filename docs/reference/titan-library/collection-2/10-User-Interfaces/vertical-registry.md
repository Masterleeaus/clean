# Titan BOS — Vertical Registry

This document is the canonical registry of all supported vertical overlays for Titan BOS.

Each vertical:
- extends shared dashboards
- loads specialized AI training
- activates lifecycle models
- injects compliance logic
- enables artefact generators

> Titan BOS operates as: one operating system — multiple specialised service platforms.

---

## Cross-Vertical Infrastructure Modules

These engines are shared across all verticals — each vertical configures them, not forks them.

### Compliance Engine
SWMS · JSA · PPE verification · certification tracking

### Evidence Engine
Before/after photos · QR presence verification · inspection scoring

### Artefact Engine
Handover reports · bond packs · compliance certificates · efficiency summaries · condition reports

### Scheduling Engine
Recurring services · event-triggered services · weather-triggered services · calendar-triggered services

### AI Knowledge Packs
Manuals · standards · inspection rules · terminology · training flows

## Vertical Selection During Onboarding

System initialisation flow:

```
1. Select vertical(s)
2. Load terminology pack
3. Load lifecycle model
4. Load compliance pack
5. Load checklists
6. Load AI knowledge base
→ Titan BOS becomes specialised instantly
```

## Multi-Vertical Mode

Companies may activate multiple vertical overlays simultaneously.

**Example — exterior services operator:**
- Pressure cleaning
- Window cleaning
- Solar panel cleaning
- Garden maintenance

Dashboards adapt dynamically per job type. Booking-level vertical selection routes the correct checklist, artefact generator, and AI context pack.
