# Agent Working Agreement

1. Work only on `agent/titan-zero-pwa-upgrade` or a child feature branch.
2. Preserve MagicAI as host, WorkCore as operational authority, Interaction Engine as interaction authority, and the existing chatbot PWA as the only mobile shell.
3. Never add a second app registry, five-tier AI runtime, service worker, IndexedDB authority, authentication system, tenant model, or billing system.
4. All WorkCore mutations go through governed action contracts. Direct operational model writes are prohibited.
5. Confidence never grants authority.
6. Donor code under `tools/donor-sources` is reference-only until adapted behind Titan contracts.
7. Use test-driven development for feature and bug changes.
8. Do not commit `.env`, credentials, private keys, caches, logs, `vendor`, `node_modules`, generated uploads, or user data.
9. Record confirmed defects, risks, and unexecuted tests honestly.
10. Before claiming completion, run fresh verification and include evidence.
